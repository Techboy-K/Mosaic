# Mosaic Restaurant

Website and staff operations portal for Mosaic Lebanese Restaurant, Abu Dhabi.

Two rooms, one kitchen: **Al Muroor** and **Al Najda**.

## Layout

```
website/            the site — static HTML, generated by the Python scripts beside it
  index.html        scroll-driven landing film
  menu.html         250 dishes across 19 categories
  crew/             staff portal (see CREW.md)
  assets/           css, js, img, video, 3d models
  data/             menu.json, delivery-zones.json
supabase/
  migrations/       schema, RLS policies, seed data (001–012)
  functions/        staff-admin edge function
vercel.json         deploy config
```

No npm, no bundler, no framework. The pages are generated:

```bash
cd website
python3 build-site.py     # public pages
python3 pages_landing.py  # landing film
python3 build-crew.py     # crew portal
python3 serve.py          # dev server on :8899 (with HTTP Range, needed for video scrubbing)
```

## Deploying

Vercel serves `website/` as a static directory — `vercel.json` sets `outputDirectory`
and the cache headers. There is no build step; commit the generated HTML.

## Authorization

Authorization lives in **Postgres Row Level Security**, not in the browser. The
client holds only the anon key, which is RLS-gated by design and safe to publish.
The service-role key and the Supabase management token are never served to a
browser and never committed — they live in `.secrets/`, which is gitignored.

The UI's permission checks are a convenience so the right things render. The real
enforcement is in the database and applies whatever the browser believes.

## Not in this repo

Kept local, deliberately: the research package (`mosaic-restaurant-research/`,
scraped third-party media), design files, the 81 MB landing-film master (the
9 MB encode ships in `website/assets/video/`), and `.secrets/`.
